# 게임 폴더

> 새 게임을 만들기 전에 **루트의 [`GAME_RULEBOOK.md`](../GAME_RULEBOOK.md)**를 먼저 보세요. 캐릭터 타입(거울뷰/그림자뷰)을 꼭 정하고 시작합니다.

run.bat 을 실행하면 `http://localhost:5000/games/` (게임 고르기 화면)가 전체 화면으로 바로 열립니다.
뷰어에서는 보기 패널의 **🎮 게임** 버튼. 모든 화면은 **손을 들어 버튼 위에 1.5초 올려 두면** 선택됩니다(마우스 불필요).

```
games/
├─ index.html          게임 고르기 화면 (새 게임은 여기 GAMES 목록에 한 줄 추가)
├─ _shared/            모든 게임이 같이 쓰는 기능
│   ├─ femto-client.js  에이전트 연결 (스켈레톤·영상·사람 이름, 떨림 필터, 가상 플레이어)
│   ├─ pose.js          팔 올림/내림, 다리 들기/내림 판정 (몸 기준이라 키·카메라 기울기와 무관)
│   ├─ players.js       1~4인 자리 배정 (화면 왼쪽부터 P1…), 트래킹이 끊겨도 같은 자리로 다시 연결
│   ├─ video-layer.js   내 모습 그리기: 배경 보이기/지우기, 사람 색 테두리 빛, 스켈레톤(옵션), 청기·백기
│   ├─ throw.js         던지기 동작 알아채기 (손이 몸 앞쪽으로 빠르게)
│   ├─ hand-pointer.js  손 커서: 손을 들어 .hand-target 버튼 위에 머무르면 선택 (마우스 대신)
│   ├─ sound.js         음성 안내(웹 음성 → 에이전트 Windows 음성 /tts → 브라우저 음성 자동 선택) + 효과음
│   └─ ui.css           공통 스타일
├─ flag/               청기백기
├─ smash/              사진 깨기 (사진에 던져서 깨기: index.html, game.js, board.js, photos.js)
└─ bead/               구슬 꿰기 (날아오는 구슬 가운데를 손으로 그어 꿰기, 그림자뷰)
    ├─ index.html       화면
    ├─ game.js          진행·판정·점수·등수
    └─ commands.js      명령 만들기 (난이도 단계)
```

## 카메라 없이 시험

주소 뒤에 `?sim=인원` 을 붙이면 가상 플레이어가 명령을 (가끔 틀리면서) 따라 합니다.
`&skill=0.3` 처럼 실력(맞힐 확률)을 정하면 자동 난이도가 내려가는 것도 볼 수 있습니다.
예: `http://localhost:5000/games/flag/?sim=3`

## 새 게임 추가

1. `games/<게임이름>/index.html` 과 `game.js` 를 만들고 `_shared` 모듈을 가져다 씁니다.
2. `games/index.html` 의 `GAMES` 목록에 한 줄 추가합니다.
   손으로 누를 버튼에는 `class="hand-target"` 을 붙이고 `HandPointer` 를 만들어 매 프레임 `update(dt)` 를 부릅니다 (flag/game.js 참고).
   어르신용: 큰 글씨·큰 버튼, 넉넉한 판정과 시간, 틀려도 부드러운 말투를 지켜 주세요.
3. 웹 파일만 바꾸면 에이전트가 자동으로 브라우저를 새로고침합니다 (다시 빌드할 필요 없음).
