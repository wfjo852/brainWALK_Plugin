# 사진 깨기 📸

사진을 향해 공을 던지듯 팔을 휙! 던지면, 공·토마토·달걀이 날아가서 사진이 조금씩 깨지는 게임입니다.
팔 운동과 스트레스 풀기용. 여러 명이 함께 던져도 됩니다(카메라에 보이는 사람 모두).

## 진행

1. **설정** (손으로도 고를 수 있음)
   - 깰 사진: 보관함의 사진이 **번호 순서대로 모두** 나옴. 사진을 누르면 빼기/넣기 (빠진 사진은 흐리게)
   - **📱 휴대폰으로 보내기**: 오른쪽 QR 코드를 휴대폰 카메라로 찍으면 사진 보내기 페이지가 열림. 여러 사람이 보내도 됨
   - 사진 올리기(보호자, 마우스): **📷 사진 올리기** 버튼, 사진 파일을 화면에 끌어다 놓기, 또는 Ctrl+V 붙여넣기
   - **✏️ 글자로 만들기**: "스트레스", "무릎 통증"처럼 깨고 싶은 말을 큰 그림으로 만듦
   - 던지기: **살살**(가볍게 던져도 인정, 기본) / **힘껏**(세게 던져야 인정)
2. **던지기**: 손을 뒤로 뺐다가 카메라 쪽으로 휙. 오른쪽에서 던지면 사진 오른쪽, 높이 던지면 위쪽에 맞음
   - 던지는 것(⚾ 공 / 🍅 토마토 / 🥚 달걀)은 **던질 때마다 무작위** (바로 전과 같은 건 연달아 안 나옴)
3. 사진이 88% 깨지면 남은 조각이 와장창 → 잠시 뒤 **다음 사진** → 모두 깨면 **결과**
   (깬 사진 수, 던진 횟수, 걸린 시간, 가장 센 던지기, 사람별 횟수) → 다시 깨기 / 사진 고르기 / 다른 게임

## 화면

위쪽 안내 띠 = 안내 말·사진 번호(1/4)·깨진 정도·사람별 던진 횟수(이름 옆 색)·**사진 보내기 QR**(게임 중에도 계속 받음),
그 아래 줄 = **대기 중인 사진**(게임 중 휴대폰으로 온 사진은 줄 맨 뒤에 붙음), 아래 = 사진판.

캐릭터 타입: **그림자뷰** (`GAME_RULEBOOK.md`) — 카메라 영상은 안 보이고, 사진 위에 사람이 번진 그림자(60% 검정)로 겹쳐 보임.
그림자 테두리에 그 사람 색의 옅은 글로우(던진 물건·맞은 자리와 같은 색). 그리는 순서: 사진판 → 그림자 → 날아가는 것·조각·"쾅!".
던진 물건·꼬리·맞은 자리 고리·"쾅!" 글자는 **던진 사람 색**이라 누가 맞혔는지 알 수 있습니다.

## 던지기 판정 (`_shared/throw.js`)

- 가슴 기준으로 손이 카메라 쪽(앞)으로 빠르게 나가면 던지기 → 걸어서 다가오는 건 던지기가 아님
- 살살: 앞으로 0.75 m/s 이상 + 14cm 이상 / 힘껏: 1.2 m/s 이상 + 22cm 이상
- 손이 배꼽보다 위일 때만 (밑으로 던지기도 인정), 같은 손은 0.6초에 한 번
- 세게 던질수록 크게 깨짐 (힘 35~100%)

## 깨지는 방식 (`board.js`)

- 사진을 약 180개 삼각형 조각으로 나눔. 맞은 곳 가까운 조각일수록 많이 상하고, 다 상하면 떨어져 나감
- 가장 가까운 조각은 매번 떨어짐 (던질 때마다 뭔가 깨지게). 빈 곳을 맞히면 가까운 남은 조각으로 맞혀 줌
- 깨진 자리 뒤에는 "😊 후련해요!"가 보임
- 보통 25~40번 던지면 다 깨짐

## 사진 보관 (`photos.js`)

- 이 PC의 브라우저 저장소에만 보관 (인터넷으로 보내지 않음). 긴 쪽 1280px로 줄여 저장, 최대 40장

## 휴대폰 사진 받기 (QR)

- 휴대폰과 게임 PC가 **같은 와이파이**여야 함. 에이전트를 처음 켤 때 Windows 방화벽 창이 뜨면 **허용** (개인 네트워크)
- QR 주소: `http://(PC 주소):5000/up/?t=(토큰)` — 토큰은 에이전트를 켤 때마다 새로 생김 (QR을 본 사람만 올릴 수 있게)
- 휴대폰 페이지(`wwwroot/up/`)가 사진을 긴 쪽 1600px JPEG로 줄여서 보냄 → 에이전트가 메모리에 잠시 보관(최대 60장, 한 장 15MB)
  → 게임 화면이 1.5초마다 가져가서 보관함에 넣고 에이전트에서 지움
- 다른 기기(휴대폰)는 `/up/` 페이지와 `POST /api/up`만 쓸 수 있음. 게임·뷰어·스켈레톤 데이터는 이 PC에서만
- 끄려면 에이전트를 `--no-lan` 으로 실행 (예전처럼 이 PC에서만 접속)
- 사진 위에 마우스를 올리면 나오는 ✕ 로 지우기
- 처음 켜면 "스트레스", "걱정 근심", "짜증" 글자 그림이 들어 있음

## 카메라 없이 시험

`?sim=1&autothrow=1` → 가상 플레이어가 1.4초마다 던짐. 게임 중 **Space** = 가운데로 한 번 던지기.
