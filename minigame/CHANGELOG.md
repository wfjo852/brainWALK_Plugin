## v2.4 — 2026-11-17 (테두리 빛·화면 설정, 먼저 한 사람 보너스, 사진 깨기 색 구분)

**화면 (모든 게임 공통, `_shared/video-layer.js`)**
- 카메라 **원래 배경을 보여 줌** (조금 어둡게 해서 사람이 또렷하게)
- 사람 윤곽에 **그 사람 색(P1 빨강, P2 파랑, …)으로 빛나는 테두리**. 마스크는 사람인지 아닌지만 알려 주므로, 윤곽 점마다 가장 가까운 사람의 관절 색으로 칠함
- 스켈레톤은 **옵션**: 기본은 숨김 (영상이 없는 가상 플레이어일 때는 항상 보임)
- 청기백기 설정 화면 "화면": 배경 보이기/지우기, 스켈레톤 보이기/숨기기 (손으로도 고름, 이 PC에 저장 `femto.view`)
- 빛은 영상이 새로 올 때 작은 그림에서 한 번만 번지게 해서 가벼움 (그리기 부담 약 1.5ms)

**청기백기 점수**
- 2명 이상일 때 **먼저 한 순서 보너스**: 1등 +20, 2등 +10, 3등부터 0 (같은 순간이면 같은 등수). 머리 위에 "1등! +220"처럼 표시
- 결과에 "먼저 N번" 표시 → 동점이 거의 안 나옴 (가상 3명 시험: 2,520 / 2,220 / 1,985점)

**사진 깨기**
- 화면에 **사람 모습 없이 사진만** (사진판이 아래 칸 전체). 사람 영상도 받지 않음
- 던진 물건이 **던진 사람 색**: 공 = 그 색 공, 토마토·달걀 = 그 색 동그라미 위에. 꼬리·맞은 자리 고리·"쾅!" 글자도 같은 색
- 물건은 화면 아래, 던진 사람이 서 있는 쪽에서 날아감. 위 카드(이름·색·던진 횟수)와 색이 같음
- 두 사람이 같은 색을 받지 않도록 색 배정 수정

- 반영: 웹 파일만 → 다시 실행 불필요

## v2.0 — 2026-11-10 (팔만 모드 명령 다양화)

- 문제: "팔만" 모드에서는 명령이 "오른팔/왼팔 올려" 위주(문장 약 8개)라 지루함

  3. 섞어서·~말고 — "오른팔 올리고 왼팔 옆으로!", "백기 말고 청기 올려!"

  5. ~하지 마·긴 이어가기(4번, 옆으로 포함), "반대로! … 옆으로!"

- 이어가기: "내려" 없이 다음 명령, 화면에 "🔗 이어가기 1/3". 바꾸는 순간 잠깐 맞는 자세는 성공으로 안 침(0.4초 유지)
- 이어가기는 쉬는 시간·판 끝을 넘지 않음. 팔·다리 모드 명령은 그대로

## v1.6 — 2026-11-10 (안내 띠 화면 + 음성 안내 강화 + 자동 난이도)

**화면 구성** (청기백기)
- 위쪽 = **안내 띠**(명령·준비·카운트다운·진행 막대), 아래쪽 = **내 모습·스켈레톤**. 서로 겹치지 않음

**음성 안내 (TTS)** — 쓸 수 있는 것 중 가장 좋은 것을 자동 선택
1. 웹 음성: Edge의 자연스러운 한국어 온라인 음성(SunHi Online 등, 인터넷 필요)
2. 에이전트 음성(새 파일 `TtsService.cs`, `/tts`): 에이전트가 Windows 한국어 음성(Heami)으로 소리를 만들어 보냄 → 인터넷·브라우저 음성 없어도 동작, 명령 문장을 미리 만들어 둠
3. 브라우저 기본 한국어 음성
- 1번이 막히거나 1.5초 안에 시작하지 않으면 자동으로 2번으로 바꿈. 설정 화면 아래에 지금 쓰는 음성 표시

**자동 난이도** (난이도 선택 없앰)
- 9단계: 명령 종류(한 팔 → … → ~하지 마) + 반응 시간 + "내려" 시간이 함께 바뀜. 항상 1단계(가장 쉽게)로 시작
- 올림: 최근 3번 평균 0.8 이상 (성공 1, 느린 성공 0.7, 틀림·놓침 0 / 여러 명이면 평균)

- "잘하시네요! 조금 더 어렵게 해 볼게요" / "괜찮아요, 조금 쉽게 해 볼게요" 음성·화면 안내, 결과에 최고 단계

## v1.3 — 2026-11-09 (카메라 기울기·바닥 보정, 떨림 보정)

**기울기·바닥 보정**
- Femto Bolt 내장 기울기 센서(IMU) 가속도로 중력 방향을 재서, 카메라가 기울어져 있어도 아바타·3D가 똑바로 서게 함
  (Microsoft floor_detector 샘플과 같은 방식: 가속도계 → 깊이 카메라 회전 후, 가만히 있을 때의 값 = 위쪽 방향).
- 상태 패널에 `카메라 기울기: 아래로 X°, 옆으로 Y°` 표시. 보기 패널의 **기울기·바닥 보정**으로 켜고 끔 (기본 켬).
- 바닥 높이: 발이 내려가면 바로, 올라가면 천천히 따라감 → 점프·발 들기에 바닥이 따라 올라가지 않음.
- IMU를 켤 수 없으면 콘솔에 안내하고 보정 없이 동작. 데모 카메라는 일부러 아래 8°, 오른쪽 5° 기울어져 있음.

**떨림 보정 (One Euro 필터)**
- "부드럽게" → **떨림 보정** 슬라이더로 변경 (0 = 끔, 기본 0.6). 데이터를 받을 때 관절마다 필터를 걸고, 화면 보간은 짧게만.
- 가만히 있을 때는 강하게, 빠르게 움직일 때는 약하게 → 떨림은 줄이고 지연은 거의 없음.
- 시뮬레이션(떨림 ±10mm): 가만히 서 있을 때 떨림 72% 감소, 천천히 움직일 때 48% 감소(정확도 동일),
  빠른 손 흔들기(1.5Hz·25cm)도 지연 없이 따라감. 가려진(추정) 관절은 더 강하게 거름.
