# 구슬 꿰기 📿

사방에서 날아오는 구슬의 **가운데 구멍**을 손으로 휙! 그으면 내 실에 꿰어지는 게임입니다.
가끔 섞여 나오는 💣 폭탄은 건드리면 안 됩니다. 팔을 크게 휘두르는 운동과 순발력용입니다.

- 캐릭터 타입: **그림자뷰** (`GAME_RULEBOOK.md`) — 사람은 번진 그림자, 배경은 게임이 그리는 밤하늘
- 인원: 최대 참여 인원(공통 설정, 기본 4명)까지. 게임 중에 들어와도 자리가 남으면 참여

## 진행

1. **설정**: 시간 고르기 (1분 / 2분 / 3분, 손으로도 고름) → 시작
2. **준비 → 3·2·1**
3. **게임**: 정한 시간 동안 구슬이 묶음으로 날아옴 → 시간이 끝나면 **결과**(등수)

## 규칙

| 무엇 | 어떻게 |
|---|---|
| 구슬 | 한 번에 **1~5개**. 아래 · 왼쪽 · 오른쪽에서 포물선으로 날아옴 (한 묶음은 같은 쪽에서) |
| 꿰기 | 손을 **빠르게**(0.8 m/s 이상) 휘둘러, 손이 지나간 선이 구슬 **가운데**(반지름의 65% 안, 점선 고리)를 지나면 꿰어짐 |
| 폭탄 | 묶음마다 25% 확률로 하나 섞임 (시작 6초 뒤부터). 손이 **닿기만 해도** 꿴 구슬 **3개**를 잃음 |
| 놓친 구슬 | 그냥 사라짐 (벌점 없음) |
| 등수 | 시간이 끝났을 때 **꿴 구슬 수**. 같으면 공동 등수 |

- 가만히 댄 손이나 천천히 움직이는 손으로는 꿰어지지 않습니다. 빠르기는 화면이 아니라 실제 손 빠르기(m/s)로 재서, 카메라와의 거리와 상관없이 같습니다.
- 손 위치는 그림자와 같은 자리입니다. 그림자 손이 지나간 곳에서 꿰어집니다.
- 숫자는 `game.js` 위쪽 `RULE`에서 바꿉니다.

## 화면

- 가운데 위: 남은 시간(10초 남으면 노랗게 깜빡임) · 안내 한 줄
- 양옆: **사람마다 실 한 줄** (P1 왼쪽, P2 오른쪽, P3 왼쪽 안, P4 오른쪽 안). 이름 · 꿴 개수, 꿴 구슬이 위부터 쌓임
- 휘두를 때 손 자국이 그 사람 색으로 남음

## 효과

- **꿸 때**: 구슬 색 반짝이·별, 그 사람 색 고리, "+1"(한 번에 여러 개면 "3개 한 번에!"),
  구슬이 그 사람 색 실에 끌려 실까지 날아가 "톡" 하고 꿰어짐. 꿸수록 "띵" 소리가 조금씩 높아짐
- **폭탄**: 불꽃 폭발, 화면 흔들림, 그 사람 실이 빨갛게 번쩍, 잃은 구슬이 실에서 떨어짐, "💣 -3"

## 카메라 없이 시험

`?sim=2&autoplay=1` → 가상 플레이어가 오른손을 계속 휘두름. Esc = 설정 화면으로.
