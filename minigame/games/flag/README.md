# 청기백기 (팔·다리, 1~4인, 어르신용)

말하는 대로 팔과 다리를 올리고, "내려!" 하면 제자리로 돌아오는 게임입니다.
오른손에는 **청기**(파랑), 왼손에는 **백기**(흰색)가 화면에 달려 있습니다.
마우스 없이 **손을 들어 버튼 위에 1.5초 올려 두면** 눌립니다.

## 진행

1. **설정**: 인원(1~4명), 동작(팔·다리 / 팔만), 횟수(10·20·30번 = 약 1·3·5분). 난이도는 자동
2. **준비**: 모두 두 손을 위로 올리면(0.8초) 시작. 보호자는 Space 키로 바로 시작, Esc로 게임 다시 시작(설정 화면)
3. "손 내리세요" → **3·2·1** → **명령 → 내려!** 반복. 명령 10개마다 12초 쉬는 시간
4. **결과**: 칭찬 한마디, 점수 순 등수, 성공 수, 높이, 반응 시간, 최고 기록 → 다시 하기 / 설정 바꾸기 / 다른 게임

⚠ 다리를 들 때는 의자 등받이나 벽을 잡도록 안내해 주세요. 균형이 걱정되면 **팔만**을 고르세요.

## 명령 단계 (명령 5개마다 한 단계씩 오름)

| 단계 | 내용 | 예 |
|---|---|---|
| 1 | 한 팔 | 오른팔 올려! |
| 2 | 팔·다리 하나 (팔만: 한 팔) | 왼발 들어! |
| 3 | ~말고 | 오른발 말고 왼팔 올려! (오른발을 들면 틀림) |
| 4 | 두 개 동시 | 오른팔 올리고 왼발 들어! |
| 5 | ~하지 마 | 왼팔 올리지 마! (가만히 있으면 성공) |

### 팔만 모드 명령 (다리 없이도 다양하게)

| 단계 | 새로 나오는 명령 | 예 |
|---|---|---|
| 1 | 한 팔 올리기 | 오른팔 올려! |
| 2 | 만세·옆으로·청기백기 이름 | 두 팔 다 올려! / 왼팔 옆으로 벌려! / 청기 올려! (청기 = 오른팔, 백기 = 왼팔) |
| 3 | 섞어서·~말고 | 오른팔 올리고 왼팔 옆으로! / 백기 말고 청기 올려! |
| 4 | 반대로·이어가기 | 반대로! 청기 올려! (→ 왼팔) / 청기 올려 → 백기 올려 → 청기 내려 (내리지 않고 이어서) |
| 5 | ~하지 마·긴 이어가기 | 백기 올리지 마! / 4번 이어가기 |

- 옆으로 벌리기: 손목이 어깨 높이 근처에서 몸 바깥쪽으로 쭉 나가면 인정
- 이어가기: 지금 어느 팔이 올라가 있는지 기억해야 함. 그대로 있어야 할 팔을 움직이면 틀림

### 자동 난이도 (commands.js `TIERS`, `Adapt`)

항상 1단계로 쉽게 시작합니다. 명령마다 결과를 점수로 매겨(성공 1, 느린 성공 0.7, 틀림·놓침 0, 여러 명이면 평균)
- 최근 3번 평균 0.8 이상 → 한 단계 **어렵게** ("잘하시네요! 조금 더 어렵게 해 볼게요")
- 2번 연속 거의 못 하거나 최근 3번 평균 0.5 미만 → 한 단계 **쉽게** ("괜찮아요, 조금 쉽게 해 볼게요")
- 내려간 직후에는 4번을 지켜본 뒤에 올림

| 단계 | 명령 | 반응 시간 | "내려" 시간 |
|---|---|---|---|
| 1 | 한 팔 | 기본의 1.6배 | 3.0초 |
| 2~3 | 팔·다리 하나 | 1.5 → 1.35배 | 2.8 → 2.6초 |
| 4~5 | ~말고 | 1.35 → 1.2배 | 2.6 → 2.3초 |
| 6~7 | 두 개 동시 | 1.2 → 1.05배 | 2.2 → 2.0초 |
| 8~9 | ~하지 마 | 1.05 → 0.95배 | 2.0 → 1.8초 |

음성 안내가 끝날 때까지 다음 동작을 시작하지 않고, 반응 시간은 명령을 다 읽은 순간부터 셉니다. "내려" 후 다 내리지 못했으면 2.5초 더 기다립니다.

## 화면

위쪽 안내 띠 = 명령·진행 막대·점수 카드, 아래쪽 = 내 모습 (겹치지 않음).
캐릭터 타입: **거울뷰** (`GAME_RULEBOOK.md`) — 카메라 영상 그대로, 사람 윤곽에 그 사람 색으로 빛나는 테두리.
인원(최대 인원, 기본 4명)과 스켈레톤 보이기/숨기기는 공통 틀(`_shared/game-shell.js`)에서 정함 — 인원은 게임 고르기 화면, 스켈레톤은 아래 푸터.
시작할 때 보이는 사람(최대 인원까지)으로 진행하고, 그 뒤에는 인원을 고정함.

## 음성

웹 음성(Edge 온라인 한국어) → 에이전트 음성(Windows 한국어, `/tts`) → 브라우저 음성 순서로 자동 선택. 한 화면에서는 한 목소리만 씁니다(중간에 섞이지 않음). 설정 화면 아래에 지금 쓰는 음성이 표시됩니다.

## 판정 (어르신 기준으로 넉넉하게)

- 팔 올림: 손목이 어깨보다 몸통 길이의 10% 이상 위 (약 5cm) / 팔 내림: 어깨보다 충분히 아래
- 다리 들기: 한쪽 발목·무릎이 반대쪽보다 몸통 길이의 14% 이상 위 (약 7cm)
- 정해진 팔다리를 0.15초 유지하면 성공. 다른 팔다리를 0.35~0.6초(단계별) 들고 있어야 틀림 → 살짝 움찔한 건 봐줌
- 앞 명령에서 내리지 않고 들고 있으면, 먼저 다 내려야 다음 판정이 시작됩니다
- 판정 기준값은 `_shared/pose.js` 맨 위 `TH`, 시간 값은 `game.js` 맨 위 상수에서 바꿀 수 있습니다

## 점수

- 성공: **100** + 빠르기 최대 **50** + 높이(얼마나 들었는지, 팔은 머리 높이 = 만점) 최대 **50** + 연속 성공 보너스(최대 **50**)
- "~하지 마!"를 잘 참으면: **100** + 연속 보너스 ("잘 참았어요!")
- 틀림("아까워요")·놓침("괜찮아요"): 0점, 감점 없음, 연속 끊김
- 먼저 한 순서 보너스 (2명 이상): 1등 **+20**, 2등 **+10**, 3등부터 0 (같은 순간이면 같은 등수)
- 등수: 점수 → 성공 수 → 평균 반응 시간 순
