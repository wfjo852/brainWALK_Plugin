# 벽 구멍 통과 🧱

두 손으로 공을 잡고, 저 멀리서 다가오는 벽의 **구멍 높이**에 맞춰 공을 올리고 내려서 통과시키는 게임입니다.
던지는 게 아니라 **높낮이만** 맞춥니다. 벽은 점점 빨라지고, 끝까지 버틴 사람이 1등입니다. 팔을 올리고 내리는 운동과 집중력용입니다.

- 캐릭터 타입: **그림자뷰** (`GAME_RULEBOOK.md`) — 사람은 번진 그림자, 배경은 게임이 그리는 하늘과 트랙
- 트랙: **최대 참여 인원**(공통 설정, 기본 4명) 수만큼 나란히. 사람은 서 있는 자리(화면 왼쪽→오른쪽)에 가까운 트랙을 받음
- 참가: 공 잡기 단계까지 들어온 사람. 게임이 시작되면 새로 참여하지 않음
- 등수: **통과한 벽 수**. 같으면 공동 등수

## 진행

1. **설정**: 규칙 보기 → 시작
2. **공 잡기**: 트랙마다 바닥에 공이 하나씩. **두 손을 가까이 모으면** 내 트랙의 공이 손으로 올라옴
   - 들어온 사람이 모두 잡으면 시작. 한 명이라도 잡고 15초가 지나면 나머지를 기다리지 않고 시작
3. **준비 → 3·2·1**
4. **게임**: 벽이 계속 다가옴 → 모두 탈락하면 **결과**(등수)

## 규칙

| 무엇 | 어떻게 |
|---|---|
| 공 위치 | 화면에 보이는 **두 손 사이**. 손을 움직이면 공이 그대로 따라감 (내 트랙 밖·벽 위아래로는 나가지 않음) |
| 벽 | 모든 트랙에 한꺼번에 다가옴. 트랙마다 **동그란 구멍** 하나 |
| 구멍 자리 | 레일 안 **가로 3(왼쪽·가운데·오른쪽) × 세로 3(아래·가운데·위)** 중 **레일 정중앙을 뺀 8곳**. 이전 구멍과 같은 자리는 안 나오고, **멀리 떨어진 자리일수록 잘 나옴**(거리² 비율). 높이는 벽이 출발할 때 그 사람 몸에 맞춰 손이 닿는 범위(가슴 아래 몸통 1.15배 ~ 가슴 위 0.9배) 안, 좌우는 레일 가운데에서 몸통 1.6배 안(혼자 해서 레일이 넓어도 팔이 닿게)이라, 키가 달라도 카메라에서 멀거나 가까워도 닿을 수 있음 |
| 손 표시 | 사람마다 두 손 위치에 그 사람 색 ✋ 동그라미. 두 손을 모으면 손끼리 선으로 이어짐. 공을 잡고 있으면 공 위에 테두리만 (공과 손이 함께 보이게), 공이 트랙 끝에 막혀 손과 떨어지면 손 → 공 점선 |
| 안내 | 다음 벽의 구멍이 올 자리를 **점선**으로 보여 줌. 공이 벗어나 있으면 공 옆에 구멍 쪽을 가리키는 노란 **화살표**, 맞으면 초록. |
| 통과 | 벽이 공 자리에 오는 순간 공(가운데)이 동그란 구멍 안이면 **+1** (테두리에 공 반지름의 40%까지 걸쳐도 봐줌). 별·색종이 폭죽, 겹겹 고리, 레일 빛기둥, 구멍 테두리 번쩍, "+1 좋아요!" 같은 칭찬 글자, 올라가는 화음. 5개마다 "🔥 N개 연속!" |
| 탈락 | 공이 벽에 닿거나, 그 순간 공을 놓친 상태면 탈락. 그 사람 레일(그림자·공·이름표 포함)이 **흑백**으로 바뀜 |
| 공 놓침 | 두 손이 50cm 넘게 0.6초 벌어지면 공이 바닥으로. 두 손을 다시 모으면 또 잡힘 |
| 멀리 선 사람 | 카메라에서 멀면 손 인식이 흔들리고 끊기기 쉬워서: 손 관절이 불확실하면(신뢰도 2 미만) **손목**을 쓰고, **2.5m보다 멀면** 1m마다 잡기·놓치기 거리와 놓치기 시간을 35%씩 너그럽게(최대 1.6배), 손이 잠깐 안 보여도 **0.6초**는 마지막 위치 유지. **3.6m보다 멀면** "한두 걸음 앞으로 와 주세요" 안내(글자 + 공 잡기 때는 말로도) |
| 속도 | 첫 벽은 6.5초 동안 다가옴. 벽마다 6%씩 빨라짐 (가장 빠르면 2.2초) |

- 어르신 안전을 위해 바닥까지 몸을 숙이지 않아도 됩니다. 두 손만 모으면 공이 잡힙니다.
- 숫자는 `game.js` 위쪽 `RULE`에서 바꿉니다.

## 화면

- 트랙 맨 앞(발밑) 이름표: 이름 · 통과한 벽 수 (실시간), 탈락하면 `탈락 N`
- 위쪽 가운데: 통과한 벽 수 · 속도(×배)
- 결과: 🥇🥈🥉 등수 · 통과한 벽 수 · 칭찬 한마디

## 카메라 없이 시험

`?sim=2&autoplay=1` → 가상 플레이어가 공을 잡고 두 손을 구멍 쪽으로 옮김. 벽이 빨라질수록 늦고 부정확해져서 하나씩 탈락합니다. Esc = 설정 화면으로.
